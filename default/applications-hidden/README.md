Desktop entries hidden from the launcher. Each file shadows the entry of the
same name in /usr/share/applications (the installer copies them to
/usr/local/share/applications, which comes first in XDG_DATA_DIRS).

- avahi-discover, bssh, bvnc: Avahi's network browsers, pulled in as dependencies.
- uuctl: uwsm's unit manager, a tool for debugging sessions.
- lstopo: hwloc's hardware viewer, pulled in as a dependency.
- qt6ct: Qt settings; the theme command manages Qt colours and icons.
