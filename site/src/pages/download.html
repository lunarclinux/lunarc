── Check the download

The checksum shows the file arrived intact. The signature shows it was made with the Lunarc signing key, whose fingerprint is:

{{key.fingerprint_spaced}}

Get the key from this site: {{key.file}}. It's the same key that signs Lunarc's packages, and every Lunarc install has it in the lunarc-keyring package.

  1. Check the checksum, in the folder you downloaded to. The output must match the SHA-256 above.

    sha256sum {{release.file}}

  2. Check the key's fingerprint matches the one above, then import it:

    gpg --show-keys {{key.file}}
gpg --import {{key.file}}

  3. Check the signature:

    gpg --verify {{release.sig_file}} {{release.file}}

    It must say Good signature from "Lunarc Package Signing". A warning that the key "is not certified with a trusted signature" is expected: it only means you haven't signed the key yourself.

On Windows, PowerShell prints the checksum: Get-FileHash .\{{release.file}} -Algorithm SHA256. Gpg4win provides gpg.

── System requirements

  • A 64-bit PC (x86_64) that starts in UEFI mode. Older BIOS-only computers aren't supported.
  • Secure Boot turned off (see below).
  • An internet connection while installing: the installer downloads packages. Wired or Wi-Fi.
  • Disk: the whole disk, or at least 40 GB of free, unpartitioned space to install next to Windows. The installer sets no other minimum; it's tested on a 60 GB disk.
  • Memory: the installer doesn't check; it's tested with 8 GB. The live system's "copy to RAM" option also holds the whole image ({{release.size}}) in memory.
  • Graphics: AMD, Intel, or NVIDIA GTX 16xx / RTX 20xx and newer with NVIDIA's driver. Older NVIDIA cards use the open-source nouveau driver.
  • A USB stick of at least 4 GB.

── Write it to a USB stick

Any one of these:

  • Ventoy: install Ventoy on the stick once, then copy the ISO onto it like any file. The stick can hold several ISOs.
  • Fedora Media Writer (Windows, macOS, Linux): choose "Select .iso file". Impression or Disks (Linux): pick the ISO and the stick.
  • dd (Linux), replacing /dev/sdX with the stick, not a partition of it. Check with lsblk first: everything on that device is erased. 
    sudo dd if={{release.file}} of=/dev/sdX bs=4M status=progress oflag=sync

── Secure Boot

Lunarc doesn't support Secure Boot yet: turn it off in the computer's firmware settings (often F2, Del or F10 at power-on) before starting from the stick. If Windows on the same computer uses BitLocker, it may ask for its recovery key once after this change; have the key at hand.

── Then

Start the computer from the stick. Lunarc starts a live desktop you can try without changing anything; Install Lunarc in the menu installs it. Installing walks through it, including installing next to Windows.
